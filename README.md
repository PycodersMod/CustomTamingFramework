## 工程结构

可构建项目位于 [forge/1.20.1/](forge/1.20.1/)。仓库共享元数据保留在根目录。

## 构建

请进入目标目录并运行 Gradle Wrapper。

Windows PowerShell：

```powershell
cd forge/1.20.1
.\gradlew.bat clean build
```

Linux/macOS：

```sh
cd forge/1.20.1
./gradlew clean build
```
